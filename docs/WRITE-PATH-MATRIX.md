## Legend

- **Verdict PASS**: payload supplies every column/claim the policy's `WITH CHECK`/`USING` requires.
- **Verdict PASS-dependent-on-role**: PASS iff caller holds the role the policy demands
  (fail-closed otherwise; no bypass).
- **Verdict GAP + exact gap**: quotes the policy requirement AND the payload shortfall.
- **Atomic?**: YES = single statement or SECURITY DEFINER RPC transaction.
  NO = sequential statements with partial-failure surface (stated, not fixed — Phase 0b).
- **Live-probe**: PROBED-OK / PROBED-FAIL / CODE-ONLY (mock suite only).
- No cell is UNVERIFIED: every "missing" below was confirmed by repo-wide search, with the
  search scope quoted.
